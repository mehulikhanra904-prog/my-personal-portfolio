## 📂 Project Structure

```text
my-personal-portfolio/
│
├── assets/
│   └── mehuli.jpg
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### File responsibilities

**index.html**

Contains the complete semantic structure of the portfolio, including navigation, hero section, about section, skills, projects, journey, education, contact section, and footer.

**style.css**

Contains the visual system, responsive layouts, animations, cards, buttons, typography, backgrounds, hero visuals, badges, and mobile breakpoints.

**script.js**

Handles client-side interactions such as navigation behavior, scrolling, animations, menu interactions, and other dynamic UI functionality.

**assets/**

Contains portfolio assets such as the profile image and other static resources.

## ⚡ Performance & Deployment

The project is a lightweight static frontend and can be deployed directly to Vercel.

### Deployment

1. Push changes to GitHub.
2. Import the repository into Vercel.
3. Select the project root.
4. Deploy.
5. Every push to the connected branch can trigger a new deployment.

### Production URL

**https://my-personal-portfolio-alpha-ten.vercel.app/**

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/mehulikhanra904-prog/my-personal-portfolio.git
```

Move into the project:

```bash
cd my-personal-portfolio
```

Because this is a static HTML/CSS/JavaScript portfolio, no framework installation is required.

You can open `index.html` directly in a browser, or use VS Code Live Server for a better development experience.

### Using VS Code Live Server

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
